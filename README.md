# CODSOFT TASK 1 - NUMBER GUESSING GAME

## About the Project

This project is a console-based Number Guessing Game developed using C++ as part of the CodSoft C++ Programming Internship.

The program generates a random number between 1 and 100. The user has to guess the number, and the program provides feedback after each attempt.

## Features

- Generates a random number between 1 and 100
- Takes guesses from the user
- Provides "Too High" and "Too Low" feedback
- Counts the number of attempts
- Allows the user to play again
- Simple console-based interface

## Technologies Used

- C++
- Standard C++ Libraries

## Concepts Used

- Variables
- Input and Output
- Conditional Statements
- Loops
- Random Number Generation
- Basic Functions from C++ Libraries

## How to Run

Compile the program using:

g++ number_guessing_game.cpp -o number_guessing_game

Run using:

./number_guessing_game
